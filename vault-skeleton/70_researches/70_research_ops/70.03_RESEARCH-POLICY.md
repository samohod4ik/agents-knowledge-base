# Research Policy

## Numbering

Нумерация vault (`00_`–`90_`) — папки верхнего уровня. Идентификаторы `70.xx` существуют **только** внутри `70_researches/`. Вложенный пакет провайдера — не новая область Johnny Decimal.

## Mutability

| Layer | Rule |
|-------|------|
| Evidence (`71_runs` raw) | write-once |
| Run summary | можно пересобрать |
| Evergreen | можно править |
| INDEX / registry / LOG / MOC | представления; registry — источник дедупа |

Не переносите завершённый прогон в `90_archive/`, чтобы выразить жизненный цикл. Меняйте `research_status`, `fresh_until`, `superseded_by`.

## Identity

- Один каталог на `research_run_id`.
- Не создавайте вторую папку на тот же id провайдера.
- Шаблон не везёт живые пакеты `trun_*`.

## Dedup

`canonical_key = "{scope}|{question}|{project_or_problem}"` после нормализации. Даты в ключе нет.

## Capture

Единственный разрешённый launcher deep-research — skill `save-research`. Не вызывайте провайдера в обход скилла. ADR остаются в `10_projects/<slug>/decisions.md`, не под `70_`.

## Offline

Сначала staging **вне** vault (пример: `<PROJECT_ROOT>/.cursor/research-inbox/`). `70.05_inbox/` — зона посадки после sync, не второй архив.

## Linking

У прогона есть `link_target` из закрытого набора ваших заметок. На целевой заметке — `## Related Research`. Не выдумывайте карточки проектов ради ссылки.
